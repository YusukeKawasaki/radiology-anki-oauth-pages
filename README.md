# Radiology-Anki OAuth information pages

Public information pages for the operator's personal Google Drive integration.
This repository contains only the homepage, privacy policy and static styling.

- Homepage: https://yusukekawasaki.github.io/radiology-anki-oauth-pages/
- Privacy policy: https://yusukekawasaki.github.io/radiology-anki-oauth-pages/privacy.html

GitHub Pages publishes `main` at the repository root. `.nojekyll` disables Jekyll.
No build dependencies, analytics, external fonts or client-side scripts are used.
