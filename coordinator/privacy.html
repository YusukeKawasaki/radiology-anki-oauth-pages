Privacy notice

This notice describes the intended single-operator configuration of Radiology Coordinator Output, which is currently under development. A feature described as planned may not yet be active. This page does not grant access to the application or to any Google Drive files.

Information processed

The application processes generated workflow outputs such as delivery status and receipts, quality-control results, card or article identifiers, and learning-history summaries. Depending on the output, learning-history information may include review activity and changes to learning items. The fields in an output depend on the workflow stage and report type. Patient-identifying information and research datasets are outside this application’s intended output scope.

Purpose and processing route

The purpose is to monitor the operator’s personal learning workflow and make its results easier to review. The planned route is: the operator’s Linux process → the operator’s Google Drive output files → the operator’s assistant workflow → reports for the operator, including PDFs. Files selected for the assistant workflow may therefore be processed by the assistant service. Google and the assistant service process information under their own applicable terms and privacy arrangements.

Google authorization and file access

The dedicated authorization uses the drive.file permission. The application is intended to create and manage its own output files, rather than read every file in the account. The permission itself can also cover files explicitly opened or shared with an application; this workflow does not rely on that broader file-selection path. Existing read-only access uses a separate connection.

Storage and credentials

Output files are stored in the operator’s Google Drive. Local workflow state and diagnostic logs may also be retained on the Linux computer. The planned OAuth client configuration and tokens are stored in a dedicated, access-restricted Linux configuration location. They are not intended to be included in public repositories, this site, ordinary reports or shared logs. Access restrictions reduce risk but do not guarantee security.

Retention and removal

No automatic retention period is currently specified. The operator manages retained Drive outputs and local state. The operator can stop the workflow, revoke the app’s Google access in Google Account settings, remove local authorization material and delete generated outputs. Revoking authorization does not by itself delete existing files, prior reports, backups or copies already handled by another service.

Disclosure boundaries

This is not a public data-sharing service. The intended recipients are the operator and the services used in the processing route described above. This notice does not assert that no service provider processes the data. A different use or sharing arrangement should be reviewed before it is enabled.

Questions and contact

The application is operated by GitHub user YusukeKawasaki for personal use. General questions may be submitted through the public information repository’s Issues. Do not post credentials, tokens, patient information, learning records or other private data in a public issue. A private channel can be arranged by the operator when needed.

Website

These information pages contain no analytics script, advertising script, contact form or third-party embedded assets. This site is hosted on GitHub Pages. Requests to the site are handled by GitHub and its hosting infrastructure; this statement does not describe or limit the host’s own logging practices.
