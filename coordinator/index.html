Radiology Coordinator Output

Radiology Coordinator Output is a private, single-operator workflow for organizing the operator’s radiology learning outputs. It is not open for public registration.

What the workflow does

The planned workflow runs on the operator’s Linux computer and saves generated delivery receipts, quality-control reports and learning-history reports to the operator’s Google Drive. The operator can then use their own assistant workflow to review those files and prepare PDF reports.

Google Drive access

The dedicated Google authorization is intended to use the drive.file permission. The implementation is restricted to files created by this application for its output workflow. This authorization is separate from an existing read-only file-access connection; it is not intended to grant access to the operator’s entire Drive.

This information site

These pages describe the application. They do not contain learning cards, research datasets, patient data, delivery receipts, credentials or authorization tokens. This site has no sign-in form and is not an OAuth callback endpoint.

Read the privacy notice for the proposed data flow and controls, and the terms for the intended use.
